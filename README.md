# Armel Wonga · Persönliche Website

Statische persönliche Profilseite mit Informationen zu Armel Wonga und Links zu Forschungsarbeit und GitHub.

## Umfang

- Profil und fachliche Schwerpunkte
- Responsive Kartenansicht mit HTML und CSS
- Externe Verweise auf GitHub und die HCI-Forschungsgruppe

## Wartungsstand

Die Sicherheits- und Abhängigkeitsänderungen werden in [PR #1](https://github.com/awon20/awon20.github.io/pull/1) verfolgt. Sie sind noch nicht in den Quellcode-Hauptbranch übernommen. Die README-Ergänzung führt diesen Pull Request nicht zusammen.

## Lokal ansehen

```sh
git clone https://github.com/awon20/awon20.github.io.git
cd awon20.github.io
```
Anschließend `index.html` im Browser öffnen. Es werden keine npm-Pakete und kein Build benötigt. Die Google-Material-Icons werden extern geladen und benötigen eine Internetverbindung.
